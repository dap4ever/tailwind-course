# Curso JavaScript: Do Básico ao Avançado

Bem-vindo! Este mini projeto organiza lições práticas para você evoluir em JavaScript.

## Roadmap
1. Fundamentos
   - Variáveis e tipos
   - Operadores
   - Controle de fluxo (if / switch / loops)
   - Funções (declaração, expressão, arrow)
   - Arrays e Objetos
2. Intermediário
   - ES6+ (destructuring, template literals, spread/rest)
   - Módulos (import/export)
   - Manipulação de DOM (exemplos simples)
   - Erros e try/catch
   - JSON e armazenamento local
3. Avançado
   - Assíncrono (callbacks, promises, async/await)
   - Fetch API e requisições
   - Classes e herança
   - Padrões (Factory, Module, Observer - visão geral)
   - Performance e boas práticas
4. Extra
   - Testes básicos (Jest ou Vitest)
   - TypeScript introdução rápida
   - Ferramentas (lint, format)

## Como usar
Cada lição possui:
- `lesson-XX.md`: conteúdo teórico
- `demo-XX.js`: código de exemplo executável com Node
- `exercises/ex-XX.js`: exercícios para praticar (com TODOs)

Execute uma demo:
```powershell
node javascript-course/lessons/demo-01.js
```

Ou usando npm scripts prontos:
```powershell
npm run course:01
npm run course:02
# ... até 05
```

Ou de forma genérica, passando o número da lição (01-05):
```powershell
npm run course 03
```
