# Curso JavaScript · Syllabus

Bem-vindo à trilha completa de JavaScript deste repositório. O conteúdo é organizado em módulos com lições, demos e exercícios.

## Módulo 1 · Fundamentos
1. 01 · Variáveis e Tipos — docs/course/fundamentals/01-variaveis-e-tipos.md
2. 02 · Controle de Fluxo — docs/course/fundamentals/02-controle-de-fluxo.md
3. 03 · Funções — docs/course/fundamentals/03-funcoes.md
4. 04 · Arrays — docs/course/fundamentals/04-arrays.md
5. 05 · Objetos — docs/course/fundamentals/05-objetos.md

## Módulo 2 · Intermediário (próximo)
- ES6+: destructuring, template literals, spread/rest
- Módulos (import/export)
- DOM e eventos
- Erros e try/catch
- JSON e armazenamento (localStorage)

## Módulo 3 · Avançado (próximo)
- Assíncrono: callbacks, promises, async/await
- Fetch API e consumo de APIs
- Classes e herança
- Padrões: Factory, Module, Observer (visão geral)

## Extra (opcional)
- Testes com Vitest/Jest
- Introdução a TypeScript
- Lint e format

## Como executar as demos
PowerShell:
```powershell
npm run course:01
npm run course:02
# ... até 05

# genérico
npm run course 03
```

Os códigos-fonte das lições e exercícios ficam em `javascript-course/`.
