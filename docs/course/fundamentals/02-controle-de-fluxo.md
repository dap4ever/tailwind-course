# 02 · Controle de Fluxo e Operadores

Base: `javascript-course/lessons/lesson-02.md`
Demos: `javascript-course/lessons/demo-02.js`
Exercícios: `javascript-course/exercises/ex-02.js`

## Objetivos
- Dominar operadores principais
- Utilizar estruturas condicionais e loops
- Aplicar operador ternário para expressões simples

## Resumo rápido
- Use `===` ao invés de `==` para evitar coerção implícita
- Loops comuns: `for`, `while`; considere `for...of` para iterar arrays
- Switch é útil para múltiplos ramos estáticos

## Checklist de domínio
- [ ] Diferencia == de ===
- [ ] Consegue escrever laço for básico sem erro de off-by-one
- [ ] Sabe aplicar ternário em condição simples

## Exercício extra
Implemente um loop que conte regressivamente de 10 a 0 e mostre "Lançar!" no final.
