# 03 · Funções

Base: `javascript-course/lessons/lesson-03.md`
Demos: `javascript-course/lessons/demo-03.js`
Exercícios: `javascript-course/exercises/ex-03.js`

## Objetivos
- Diferenças entre declaração, expressão e arrow
- Uso de parâmetros padrão e rest
- Entender closures e captura de escopo

## Principais pontos
- Arrow functions não possuem `this` próprio
- Closures permitem estado privado
- Use rest `(...args)` para somar ou agregar valores dinamicamente

## Mini desafio
Crie uma função `makeCounter(step = 1)` que retorna um contador avançando de `step` em `step`.

## Sinais de que você dominou
- Consegue explicar closure em suas palavras
- Sabe escolher entre function declaration e arrow function conforme necessidade de `this`
